# Agent Studio Hands on Lab

This lab will equip you with a deeper understanding of AI agents, tools, and MCP– demonstrating how these technologies can be applied to solve business challenges using Cloudera Agent Studio.

!!! info
    Agent Studio is built on the Crew AI framework. After his lab we highly encourage you to take this free course: [https://www.deeplearning.ai/short-courses/multi-ai-agent-systems-with-crewai/](https://www.deeplearning.ai/short-courses/multi-ai-agent-systems-with-crewai/) if you want to dive deeper.

!!! tip
    If you are looking to better understand MCP check out this great talk by Anthropic: [Building Agents with Model Context Protocol - Full Workshop with Mahesh Murag of Anthropic](https://www.youtube.com/watch?v=kQmXtrmQ5Zg)
